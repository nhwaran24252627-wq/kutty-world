# Add your private media here

The site is ready to use with its illustrated placeholders. To make it personal, copy your photos, videos, and audio into this exact folder and use these names:

| Website place | File name |
| --- | --- |
| Opening photo | \`stage1.jpg\` |
| Six memories, in the displayed order | \`memory-01.jpg\` through \`memory-06.jpg\` |
| Hidden hug memory | \`secret-memory.jpg\` |
| Final photos | \`happiness-01.jpg\` through \`happiness-14.jpg\`, then the existing \`stage1.jpg\` and \`secret-memory.jpg\` |
| Optional final videos | \`happiness-video-01.mp4\` through \`happiness-video-05.mp4\` |
| Background music | \`audio.mp3\` |

The website has 16 places in its final stage: the 14 \`happiness-*.jpg\` files already present, followed by the existing \`stage1.jpg\` and \`secret-memory.jpg\`. Optional video cards stay hidden unless matching video files are added. Keep the file names above unless you also update the matching reference in \`../index.html\`.

For best results, use portrait photos for the memory and final-photo slots, and MP3 for the music. The music begins when the birthday girl taps **Enter our chinna ulagam**, which makes it work in browsers that prevent unprompted audio playback.
